# Portafolio Web Personal

Sitio web modular y responsivo desarrollado como parte de la asignatura DSY1104 en Duoc UC.

## 🚀 Tecnologías utilizadas

* **React.js**
* **Bootstrap 5**
* **HTML5 & CSS3**
* **JSON** (Carga dinámica de proyectos y noticias)

## 📁 Estructura del Proyecto

* `src/components/`: Componentes modulares (Navbar, Proyectos, Noticias, Contacto, etc.).
* `public/data/`: Datasets en formato JSON para la gestión dinámica de contenidos.
